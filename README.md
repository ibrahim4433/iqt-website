# innoqtech.com distro bootstrap

This distro is prepared to support creating new sample designs using:
- the same source content from the current innoqtech.com website (in the assets folder)
- the same page/subpage structure
- a future new logo (in the new-logo folder)
- new full html sample designs using the new logo and same content but new layouts and new colors and styles suitable to the website type and new logo colors...
